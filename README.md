# rosstat-parser

Локальный Jupyter-блокнот для сбора макростатистики Росстата как признаков для
прогноза курса или ставки ЦБ. Целевой ряд и пресс-релизы ЦБ собираются отдельно.

## Запуск на Mac

Подготовленная среда находится в `.venv/` (Python 3.13):

```bash
.venv/bin/jupyter lab notebooks/rosstat_macro.ipynb
```

Выполнить тот же сбор без Jupyter, используя загруженные файлы:

```bash
.venv/bin/python extract_dataset.py --offline --services-history
```

Для нового компьютера нужны Python 3.12+ и зависимости:

```bash
bash run_local.sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m ipykernel install --prefix .venv --name rosstat-local --display-name "Python (rosstat local)"
.venv/bin/python extract_dataset.py --services-history
```

`run_local.sh` проверяет загрузку восьми основных файлов и чтение всех листов.
`extract_dataset.py` формирует числовые временные ряды. Без `--services-history`
используются только восемь основных файлов, включая один выпуск услуг.

## Данные

Восстановлен каталог из **260 Excel-ссылок** по пяти исходным HTML: национальные
счета, цены, зарплаты, розница и услуги. Выбраны восемь основных файлов,
семь дополнительных и 56 архивных выпусков услуг. Все **64 файла** основного набора
и архива услуг получены по HTTPS на локальном Mac. Извлечено **2 860 значений**;
27 тестов прошли, 228 контрольных значений ИПЦ совпали. Блокнот выполнен целиком.

Размечены **14 показателей**:

| Частота | Показатели | История |
| --- | --- | --- |
| Месячная | Общий ИПЦ, продовольствие, непродовольственные товары, услуги | С 1991 года |
| Месячная | Цены производителей: промышленность, добыча, обработка, ОКВЭД2 | С 2013 года |
| Месячная | Средняя номинальная зарплата по экономике | С 1998 года |
| Месячная | Номинальный оборот розницы | Январь–сентябрь 2026 |
| Месячная | Физический объём услуг: к предыдущему месяцу и год к году | Архив выпусков 2022–2026 |
| Квартальная | ВВП: физический объём год к году, уровень в ценах 2021 года, тот же уровень с сезонной корректировкой | С 2012 / 2011 года |

`IFO_rozn_2025.xls` оказался годовым и **исключён из месячной матрицы**.
Номинальный оборот розницы не заменяет реальный индекс. Зарплата до 1998 года
выражена в тысячах рублей и исключена из рублёвого ряда. Старые классификации
ОКВЭД и разные базовые цены ВВП не объединяются. Накопительные строки исключены.
История услуг собирается из отдельных выпусков и может отличаться от позднейших
пересмотренных значений. Территориальные оговорки сохраняются в отчёте.

Разметка реальных листов и контрольных ячеек — `sources/extraction_specs.json`.
Архив услуг проходит дополнительную проверку заголовка месяца/года, строки России
и базы индекса. При изменении структуры сбор останавливается.

## Результаты

Каждый запуск сохраняет отдельную папку `data/processed/<время>/`:

- `macro_long.csv` — значения, частоты, единицы, базы, URL, SHA-256 и время получения;
- `macro_monthly.csv`, `macro_quarterly.csv` — раздельные матрицы;
- `quality_report.csv` — фактический диапазон и внутренние пропуски каждого ряда;
- `validation.json` — сверка ИПЦ с независимо расположенными строками РФ;
- `source_assessment.json` — методологические и территориальные примечания;
- `extraction_specs.json` — разметка, использованная в этом запуске;
- `download_report.json`, `selected_sources.csv` — происхождение файлов.

Пустые периоды после последнего опубликованного значения отсекаются. Внутренние
пропуски сохраняются. Квартальные значения не интерполируются в месяцы.
Исходные байты и квитанции получения лежат в `data/raw/`; при повторном чтении
проверяется SHA-256. `data/` и `.venv/` исключены из Git.

## HTTPS

Росстат использует сертификат Минцифры и не передаёт промежуточный сертификат.
Официальные корень и выпускающий сертификат сохранены в `certificates/`.
Этот bundle применяется только в сессии загрузчика; проверка TLS включена.
Системное хранилище не изменяется. Происхождение и отпечатки —
[certificates/README.md](certificates/README.md).

## Проверки

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m pip check
.venv/bin/python local_check.py --offline
```

Тесты проверяют русские числа, пропуски, месяцы и кварталы, сноски в годах,
контрольные заголовки, дубли, накопительные периоды, целостность кеша и локальный
импорт. Дополнительно реальный ИПЦ сверяется с четырьмя рядами РФ из отдельной книги.

Пересоздать каталог из сохранённых HTML:

```bash
.venv/bin/python prepare_sources.py --input-dir data/input
```

Список ссылок зафиксирован по состоянию на октябрь 2026 года. Новые публикации
требуют обновления каталога и проверки разметки.

## Что остаётся для модели

Нужны дополнительные источники промышленного производства, безработицы, базового
ИПЦ, реальных доходов, инвестиций и длинной месячной истории реальной розницы.
`period` — период наблюдения, а `retrieved_at` — время загрузки. Ни одно из них
не заменяет историческую дату публикации: `release_date` остаётся пустой.
Для ретроспективного теста нужны даты доступности и версии рядов с учётом пересмотров.
